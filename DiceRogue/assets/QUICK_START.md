# ⚡ Quick Start - Thay Assets

## Cách nhanh nhất để thay assets:

### 1. Copy file images vào đây
Đặt file images vào các thư mục tương ứng với **TÊN FILE ĐÚNG**

### 2. Tên file phải khớp chính xác:

#### Player (thư mục `player/`)
- `player.png`

#### Enemies (thư mục `enemies/`)
- `rat.png`
- `goblin.png`
- `orc.png`
- `dragon.png`

#### Items (thư mục `items/`)
- `gem-small.png`
- `ring.png`
- `blade.png`
- `crown.png`

#### Grid (thư mục `grid/`)
- `barrel.png`
- `lava.png`
- `swamp.png`
- `teleport-rune.png`

#### UI (thư mục `ui/`)
- `dice-1.png`, `dice-2.png`, `dice-3.png`, `dice-4.png`, `dice-5.png`, `dice-6.png`
- `dice-rolling.png`
- `gold-coin.png`
- `heart.png`
- `portal.png`
- `princess.png`

### 3. Reload game
- Mở game → Hard refresh (Ctrl+F5)
- Hoặc mở `test-assets.html` để test

### ✅ Xong!

**Lưu ý:**
- Không cần sửa code nếu dùng đúng tên file
- Game tự động fallback về emoji nếu file không có
- PNG với background trong suốt
